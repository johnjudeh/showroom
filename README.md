# Showroom

## Introduction

A virtual showroom for e-commerce sites built with
[ThreeJS](https://threejs.org/). Currently focussed on businesses selling
bespoke cuts of precious stone, allowing customers to select the exact cut they
need.

Checkout the [demo app](https://showroom.fly.dev/).

## How to run

You need to clone the project:

```sh
git clone https://github.com/johnjudeh/showroom.git
cd showroom
```

Make sure you have [node](https://nodejs.org/en) installed on your computer
(preferably `18.15.0`) so that you can install the dependencies:

```sh
npm i
```

Finally, build the project:

```sh
npm run start
```

And voila, you can now access the [app](http://localhost:5173/).
