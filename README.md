# Showroom

## Introduction

A virtual showroom for e-commerce sites. Currently focussed on tiling.

## How to run

You need to clone the project:

```sh
git clone https://github.com/johnjudeh/showroom.git
cd showroom
```

Make sure you have [node](https://nodejs.org/en) installed on your computer (preferably `18.15.0`) so that you can install the dependencies:

```sh
npm i
```

Finally, build the project:

```sh
npm run start
```

And voila, you can now access the [app](http://localhost:5173/).
